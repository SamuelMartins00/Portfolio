## Descrição do Projeto

O **Portfólio** é um site pessoal criado para apresentar minha trajetória como desenvolvedor, centralizando informações como:

- **Biografia** — contexto pessoal e formação acadêmica
- **Projetos** — trabalhos desenvolvidos ao longo da graduação e por conta própria
- **Skills** — hard skills (backend, frontend, ferramentas) e soft skills
- **Eventos** — participação em eventos acadêmicos e profissionais
- **Contato** — links para e-mail, LinkedIn e GitHub

## Como Rodar Localmente

Por ser um projeto estático (HTML + Tawilwind), basta abrir o `index.html` no navegador:

```bash
# Clone o repositório
git clone https://github.com/SamuelMartins00/Portfolio.git
cd Portfolio

# Abra no navegador
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

Ou utilize a extensão **Live Server** no VS Code para um ambiente de desenvolvimento com hot reload.
